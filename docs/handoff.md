## 7. 修正したバグ（すべて再現確認済み）

1. **v6**: `configs/main.yaml` に `exclude_features` が無く、棄却済み候補 9 列（うち `noise_control` は
   信号を持たないハッシュ列）が本番モデルに入った。→ 候補列を opt-in（`include_candidates`）に反転、テスト追加
2. **`feature_fraction: 0.8`**: 列を 1 本足すと全ての木で列抽出が変わる。信号ゼロの `noise_control` を
   足したときのコストが +0.53 で、実特徴量 3 本（+0.49 / +0.39 / +0.50）と同じだった。
   → スクリーニングは `feature_fraction: 1.0` ＋ノイズ対照列で実施
3. **`deterministic: True`**: `force_row_wise` が無いと効かない。同一設定で木の本数が 959 / 1273 と振れていた。
   → 修正後の残差ドリフト 0.023 秒
4. **気象の結合**: 結合キー名が特徴量 `hour_utc` と衝突し、上書き後に削除していた。
   → `WX_KEY = "_wx_hour"` に改名。**v3 と v4 はこのバグがある状態で学習されている**
5. **気象の結合（タイムゾーン）**: 公式 parquet は UTC aware、METAR は naive でクラッシュしていた
6. **`prc.compare` の判定文言**: `[+18.44, +53.51]` を「CI がゼロを含む」と表示していた
7. **提出回数カウンタ**: ログ行数（1 提出につき 2 行）を数えていて、4 回目の提出を 6/5 として拒否した
8. **`feature_parity_report` と `predict_fold` の列可視性の実装が二重化**していた
   → `visible_numeric_columns()` に一本化
