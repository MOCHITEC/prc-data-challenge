## 修正・確認事項（リスク回避）

- **バグの可能性**: ranking の 1 月末の便で「次の離陸」が 7 月になる（ヘッドウェイ最大 199 日）。既存 `rwy_headway_next_s` も該当。3h 超は欠損扱いに（queue_runway）。
- **提出前チェック**: EHAM 2026-01 の「NM 未マッチ かつ MVT−SCHED>3h」278 行と障害日 2,217 行が SCHED に流れていないこと（SCHED コピーなのは LIRF だけ）。誤ると +4〜6 秒（temporal_shift）。
- **EHAM**: 近傍 NM タクシー代理値は EHAM で一貫して悪化（2026-01 が訓練域外）。EHAM は除外か月内標準化（queue_runway）。
- **EDDF/EHAM/LSZH** には本物のコピーが事実上無い → これらの空港でコピークラスの確率を 0 に寄せる（v5 の LSZH 後退の説明候補）。
- 重複レコード組（ranking 41 組）のマッチ側は y ≈ 4,200 秒で MVT−AOBT3 ≈ 850 秒と乖離 → aobt3 に流さない（約 −1.4 秒）。
- 外部データ（OSM: ODbL、OurAirports: パブリックドメイン）を採用する場合は `docs/external_data.md` に台帳を追加すること。
