## 0. 要旨

1. 7 空港（EDDM, EGLL, LEBL, LEMD, LFPG, LIRF, LTFM）の BLOCK は「分単位 + 一様 ±6 秒ジッタ」（秒成分は 100% が [54,6]）。EDDF/EHAM/LSZH は秒分解能。コピー判定は |BLOCK−時計|≤6 秒が正しく、±60 秒窓は隣の分の偶然一致を半分拾う。
2. ±60 秒ラベルの「コピー」の大半はコピーではない。本物は aobt3 で約 11,700/433,576（純度 2.7%）、sched で約 32,000/199,634（16%）。本物の SCHED コピーの 78% が LIRF（25,135 行、LIRF DEP の 15.6%）。EDDF/EHAM/LSZH には本物のコピーが事実上無い（v5 の LSZH +52.5 秒後退と整合）。
3. ARR 側のインブロック＝予定到着コピーは LIRF だけ（8.2%、ranking 7.9%、他 ≤0.2%）。LIRF で運航者単位の DEP/ARR コピー率相関 0.83、日×運航者（運航者平均除去後）0.33。同一スタンド直前到着がコピーなら DEP のコピー率 15.5%→37.9%、1h 超遅延便で 4.9%→27.4%。
4. NM 未マッチ行 = 大幅遅延便（MVT−SCHED 中央値 ≈5,800 秒、y は普通）と LIRF の壊れた便名（AFRR89YB 型）。LIRF の dup_prefix×未マッチ 169 行は SCHED 73%、y 平均 17,593、y>3h 68 行（学習 y>3h 202 行の 34%）。
5. 同一便の重複レコード: 片方だけ NM マッチの組でマッチ側の y 平均 4,198（MVT−AOBT_3 は 853）。ranking に 41 組（未マッチ含む 28）。
6. プロキシ混合モデル（jan+jul、344,419 行）で新特徴量群 399.8→381.1（−18.7、CI95 [−38.0,−2.2]、P=0.98）。単独ではターンアラウンド −15.0（[−25.0,−6.9]、P=1.00）。本番見積り −3〜−8 秒。

秒成分が [54,6] に入る割合（一様なら 0.217）:

SCHED は全空港で秒=0。AOBT_3/EOBT_1/LOBT もほぼ分単位（EHAM AOBT_3 のみ 84%）。EDDM の BLOCK 秒ヒストグラムは 0〜5・55〜59 秒に一様、6・54 秒が約 1/4、7〜53 秒は 0 件 → 匿名化ジッタと推定。

帰結: 分単位空港で BLOCK−時計 は 60k±6 のみ。MVT の秒は行単位の出所を予言しない（分グリッド上/外で sched 率 EDDF 0.054/0.054、EHAM 0.051/0.050、LEBL 0.076/0.075…、否定的）。y mod 60 の制約は RMSE にほぼ効かない。
