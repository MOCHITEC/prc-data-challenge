Marks: **[S]** means read from the source at the URL given. **[R]** means read from this repository (file cited).
**[X]** means my own extrapolation. An estimated gain is marked [X] unless a source measured it.

Error anatomy used for the "why here" column, all [R] and quoted from the brief and the cited files:
- Unmatched rows are about 1 % of rows but about 44 % of SSE (`next_fe_2026-09-30/scouting.md` §1). The cause
  is label corruption that cannot be seen at prediction time.
- Model A is data-limited. The last doubling of rows was still worth −4.6 s, with a ratio of about 0.79 per
  doubling (`model-a-ceiling.md` §534–543). It is also capacity-saturated.
- CV→LB transfer is weak.
- A sibling note in this directory (`adv_validation.txt`, same-month 2025 vs 2026 adversarial validation on the
  flseq feature set) reports a held-out **AUC of 0.986**. `fl_nm_rate_other` alone carries 0.325 of the
  classifier gain, although its mean is 0.99 in both years [R].

## 3. On the repo's list but never measured; GM evidence raises their priority

These are **not new**: the repo already names them. I list them because the GM sources above add evidence.

- **G11 record-order (`MVT_ID`) peer features.** In this competition merry-quicksand measured −712 board MSE
  (`public-code-deep-dive` §4 #7) [R]. The GM analogue: reverse-engineering hidden row order was a named step of the
  Optiver 1st place [S, nyanp notebook above].
- **`linear_tree` retune.** Takács's Flight Quest 3rd place used linear + GBM stages [S]. kind-mango measured
  −0.88 s live with `linear_lambda` 15 [R]. We last tried it at v4 with λ = 1 (`public-code-deep-dive` §4 #4).
- **G16 LOFO / backward elimination.** PRC-2025 rank 1 used it [R]. Item #1 above is a cheaper screen to run first.
- **G4 Poisson / Tweedie.** Sendy 1st and 3rd place both found these beat L2 on an RMSE-in-seconds target [R, 02 §5.1].
  They apply only to the **plain-y member**, because g can be negative. They were never run: every experiment used
  `objective: regression` [R].
- **P11 per-airport models.** NASA Pushback 2nd and 4th place measured per-airport models beating a global model [R, 11 §1.5].
  `configs/p11_airport*.yaml` exist, but there is no record in `experiments.jsonl` [R].
- **k-fold bagged test predictions instead of a single full refit.** AutoGluon ablation (`20-…` §9) [R].
