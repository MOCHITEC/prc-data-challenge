# v28 への上積み: 窓の修正の未マッチ行の部分だけを、厳密に足す — 事前登録（2026-10-02、提出前）

## 背景

- 現在の最良は v28 = 252.4111（3 メンバーに L2 ＋ 学習した ADS-B 残差）。v29 は v28 に別の施策（L5）の変化を後から足して
  +0.12 s 悪化した（`origin/claude/peaceful-babbage-md9l2x:docs/research_2026-10-01/README.md` §7.1）。
  原因の候補の一つは、ADS-B 残差が base の予測を特徴量に使っているのに、作り直さずに base の変化だけを足したこと。
- この計算機には ADS-B の素材（adsb.lol の joined ファイル）が無く、v28 を作り直せない。

## 何をするか（近似ではない部分だけ）

ランキングの未マッチ 5,290 行のうち、ADS-B 残差が何も変えていない 2,874 行では **v28 = v16（= main_flseq の model B）が
完全に一致**し、F（`flwin_both`）の再学習 = v26 の値がそのまま「作り直した場合の値」になる（model B は model A と独立、
ADS-B 残差はこの行で 0）。そこで:

- **v30 = v28、ただし上の 2,874 行だけ v26 の値に置き換える。** 他の 341,967 行は v28 と同一。
- ADS-B 残差が変えた未マッチ 2,416 行とマッチ行は触らない（作り直さないと正しい値にならない）。

## 見込み（2025 年の OOF、M → F を 2026 年の空港別の行数で重みづけ）

- 全体 −0.48 s（ブートストラップ 95 % [−1.30, +0.31]）。うち LIRF の 101 行が −0.33 [−1.16, +0.44]、
  LIRF 以外 2,773 行が −0.155 [−0.27, −0.05]（P(悪化) 0.003）。
- v26（v16 で同じ変更）は LB −0.39。この 2,874 行は v16 と v28 で同じ値なので、LB の差は v26 の利得のうちこの行の分になる。

## 判定（LB）

- v30 < v28（252.4111）なら採用。悪化したら不採用とし、LIRF と LIRF 以外の寄与を分析して記録する。

## 結果: **v30 = 252.4077（v28 より −0.003 s）→ ほぼ 0**

この 2,874 行は v16 と v28 で同じ値、v26 と v30 でも同じ値なので、SSE の差は土台によらない。
v26 − v16 の ΔSSE −7.44 × 10⁷ s² のうち、この行の分は −5.9 × 10⁵ s²（**0.8 %**）。v26 の LB の利得の 99.2 % は、
マッチ行か、ADS-B 残差が補正する未マッチ 2,416 行から来ていた（CV では窓の修正の利得の 93 % が未マッチ行だった）。
CV の見込み（LIRF 以外 −0.155 [−0.27, −0.05]）も外れた: 2026 年の EHAM・LTFM・EDDF・LSZH の未マッチ行は、
2025 年の OOF の行と同じには振る舞わない（推論: EHAM の 2026-01-02〜07 の混乱など、`peaceful-babbage` の §4）。

## 分解の確認 — 事前登録（2026-10-02、提出前）

- **v31 = v16、ただしマッチ行だけ v26 の値**（未マッチ行は v16 のまま）。ADS-B は関わらない、きれいな比較。
- 読み方: v31 − v16 がマッチ行の分。v26 − v16（−0.39）から引いた残りが、ADS-B が補正する未マッチ行の分。
  - マッチ行が主なら: もう一方の AI が v28 の 3 メンバーを `fe_fl_rate_window: both` で作り直す価値がある。
  - 未マッチ行（ADS-B 補正あり）が主なら: v28 ではその行を ADS-B の証拠が直接補正しているので、作り直しても大半は吸収される見込み。

## 分解の結果: **v31 = 279.2069（v16 より −0.05 s）**

| v26 − v16 の LB の利得（ΔSSE −7.44 × 10⁷ s²）の内訳 | ΔSSE | 割合 |
|---|---|---|
| マッチ行（v31 − v16） | −1.00 × 10⁷ | 13 % |
| 未マッチ行のうち、v28 で ADS-B 残差が触らない 2,874 行（v30 − v28） | −5.9 × 10⁵ | 1 % |
| **未マッチ行のうち、v28 で ADS-B 残差が補正する 2,416 行**（残り） | **−6.38 × 10⁷** | **86 %** |

窓の修正の LB の利得は、ほぼ全部が「ADS-B の証拠がある未マッチ行」（LFPG 691・LEBL 431・LIRF 282 など）にあった。
v28 ではその行を ADS-B 残差がすでに補正しているので、作り直したときに残るかどうかは、残差がどれだけ吸収するかで決まる
（全部残れば v28 から −0.37 s、全部吸収されれば 0）。確かめるには、F の model B を base にして ADS-B 残差を学習し直す必要があり、
ADS-B の素材がある環境（もう一方の AI）でしかできない。近似（v28 にその 2,416 行の差だけを足す）は v29 と同じ形の賭けになるので、
提出枠を他の AI と分け合っていることも考えて、ここでは出さない。
