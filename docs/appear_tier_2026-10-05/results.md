## 3. なぜ効くか

- stage 1 の stand run は「止まっている区間」で、自スタンドかどうかを見ていない。plan.md §1 の下見のとおり、自スタンドから 50 m 以上
  離れた stand run の多くはプッシュバック後のエンジン始動の停止で、そこから求めた `t_move` は本当の off-block より 3〜15 分遅い。
  今の残差には、どの stand run が本物かを見分ける列が無かった。
- `t_leave_own_lo`（自スタンドの 50 m 以内の最後の fix）は、止まっているかどうかに関係なく「スタンドを離れた時刻」を位置で与える。
  動いた状態で最初に見えた便でも、その fix が自スタンドの上なら off-block に近い。
- `t_appear_adj`（最初の fix をスタンドまで 6 m/s で戻した時刻）は、単独では遠い便に対して精度が上がらなかった（下見）が、
  距離の列と一緒に使うと残差の木が距離に応じて重みを変えられる。

## 14. v46 の外れの原因と、C12 の上での作り直し（`plan_rebase_c12.md`）

### 14.1 原因: 差分表の作り方の誤り（4 か月の項の抜き間違い）

- v39 は v38 から b を戻して（plain の P4 だけの不動点）作った。その b（b38）で (c_A4 − c_P4) を計算すると v39 − v38 を全行で再現する
  （285,661 行一致）。
- `apply_delta12.py` は b を v39 から（P4 と 4 か月 appear を入れた不動点で）戻した。この b での 4 か月の項は、v39 に入っている項と
  **RMS 24.5 s 違う**（項そのものの RMS 44 s）。不動点が収束しない行が多く、appear の補正は b に敏感なため。
- v46 の表は「入っている 4 か月の項」を抜いたつもりで別のものを抜き、RMS 24.5 s の雑音（≒ +430 MSE）を足した。12 か月版の改善
  （≒ −400 MSE）とほぼ打ち消し合い、LB +0.026 s。依頼の式（4 か月の項をモデルで計算し直して抜く）も同じ種類の誤り。

### 14.2 CV での確認（`cv_stale.py`、1・7 月を丸ごと外す、`results/cv_stale_a2.log`）

base を動かした後（b' = b + 0.95·(flwin − b)、RMS 23 s。参考に tc_drop、RMS 24 s）で、C0（base だけ動き ADS-B の層は古い b）に対して:

| 作り方 | flwin | tc_drop |
|---|---|---|
| old: 4 か月の項をそのまま抜き、12 か月の項を古い b で | **−0.927 [−1.254, −0.655]** | −0.936 |
| swap: 同じく抜き、12 か月の項を新しい b で | −0.944 [−1.283, −0.667] | −0.938 |
| req: 依頼の式（4 か月の項も新しい b で計算し直して抜く） | −0.829 [−1.153, −0.554] | −0.835 |
| full: ADS-B の層をすべて新しい b で | **−1.151 [−1.526, −0.853]** | −1.245 |
| 参考 C0full: 今の層（plain + 4 か月）を新しい b で評価し直すだけ | −0.202 [−0.304, −0.123] | −0.290 |

- 「古い b だと効かない」（仮説 S）は棄却: old は base が動かないとき（−0.937）とほぼ同じ。
- 判定（§4 の追記）: swap と old の差 0.02 s < 0.1 → **old 型を採る**。
- 別の発見（事後）: base を変えたら ADS-B の層も新しい b で評価し直すと、それだけで −0.2〜−0.3 s。依頼の 2（base を変えたら
  ADS-B の層も作り直す）は CV で支持される。

## 15. 種 3 本の平均（`plan_bag12.md`）: **不採用**、ただし本番の作り方の問題が見つかった

|---|---|
| bag（本番の形: plain は種 1 本、増分 A12 − P12 を 3 本の平均）対 single | **+0.070 [−0.008, +0.138]** → 不採用 |

- 「plain の層」と「増分の基準にした P12」が別の当てはめだと、その差が雑音として残る（bag が single より悪いのはこのため）。
- **本番の C12 はまさにこの形**: plain の層は別セッションの 12:v2（`local_adsb_apply_swap.py`）、appear の増分はこちらのモデル。
  2026 年の行で、別セッションの 4→12 か月の差し替え（v40 − v39）とこちらの同じ差し替え (c_P12 − c_P4)(b38) は RMS 24.9 s 違い、

## 16. ファイルから b を戻す問題は不安定（2026 年、ラベル無しの確認）

- v38 から c_P4 で b を戻すと、平な不動点 3 回では v38 を RMS 15.1 s しか再現しない（5 s 超のずれが 90,944 行 = 32 %）。
  減衰付き（0.5、30 回）では RMS 5.05 s。二つの b の差は RMS 67 s。良い残差では b + c(b) が b にほとんど依らないため。
- 戻した b を変えると、候補 A は RMS 13.9 s、D は 16.3 s、4 か月の項そのものは 13.4 s 動く。差分を作るときは、ファイルを作ったときと
  同じ戻し方（A は 3 回）にそろえるか、ファイルを最もよく再現する b（D2 は減衰付き）を使う。
- 今後: 本番の base（ADS-B の層を足す前のファイル）を残しておけば、b を戻す必要がなくなる。
