## 3. なぜ効くか

- stage 1 の stand run は「止まっている区間」で、自スタンドかどうかを見ていない。plan.md §1 の下見のとおり、自スタンドから 50 m 以上
  離れた stand run の多くはプッシュバック後のエンジン始動の停止で、そこから求めた `t_move` は本当の off-block より 3〜15 分遅い。
  今の残差には、どの stand run が本物かを見分ける列が無かった。
- `t_leave_own_lo`（自スタンドの 50 m 以内の最後の fix）は、止まっているかどうかに関係なく「スタンドを離れた時刻」を位置で与える。
  動いた状態で最初に見えた便でも、その fix が自スタンドの上なら off-block に近い。
- `t_appear_adj`（最初の fix をスタンドまで 6 m/s で戻した時刻）は、単独では遠い便に対して精度が上がらなかった（下見）が、
  距離の列と一緒に使うと残差の木が距離に応じて重みを変えられる。
