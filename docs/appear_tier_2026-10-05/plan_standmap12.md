# 自スタンドの地図を 2025 年 12 か月の ADS-B で広げる — 事前登録（2026-10-07、CV の前に書く）

## 0. なぜ（下見、ラベル無し）

- 2026 年のランキングで ADS-B の結合がある行のうち、appear の列はあるが自スタンドの座標が無い（`own_ok` = 0）行が 10,459 行
  （EDDF 7,748 行 = EDDF の 22 %、LEBL 1,840 行など）。OSM に無く、2026 年の ADS-B だけの地図（`stand_map_2026`）でも決まらない
  スタンド（EDDF の B41・B42・B43・B47、V106〜V118、V134・V136・V151 など）。
- 原因は名前の付け違いではない（OSM の `108` は V108 の機体が止まる位置から約 950 m 離れた別のスタンド）。2026 年（1・7 月）は
  10 分以上止まった stand run が少なく（V108 は 6 便、ばらつき 609 m）、地図の規則（5 便以上・ばらつき 40 m 以内）を通らない。
- 2025 年 12 か月の stage 1 の stand run では、そのうち 83 か所中 58 か所が同じ規則を通る（B41 295 便・17 m、V151 275 便・7 m、
  V108 108 便・18 m など）。2026 年の 6,574 行（ランキングの 1.9 %）が自スタンドの座標を得る。
- 前回の地図（`plan_standmap.md`）では、座標が埋まった行で −17.2 s（対照より −11.9 s）だった。

## 1. スタンドの表（`docs/appear_tier_2026-10-05/stand_map12.py`）

- **fill**（今の本番）: OSM、無ければ 2026 年の地図。
- **fill12**: fill、それでも無ければ「2025 年の地図」。2025 年の地図は、地図の規則（`stand_dur` ≥ 600 s の stand run の最後の fix
  の位置、callsign または便名の結合、(空港, 正規化した `STAND_mvt`) ごとの緯度・経度の中央値、5 便以上、ばらつき 40 m 以内）を
  2025 年と 2026 年の stand run に当てたもの。ただし **2025 年の行には、その行の月の stand run を除いた地図**を使う（月を 1 つ抜いた
  地図を 12 枚作る）。自分の stand run が自分のスタンドの位置を決める循環を避けるため。2026 年の行には全部の月を使った地図。
  スタンドの名前で特別扱いはしない（規則だけで決める）。
- **rand12**（対照）: fill12 で「2025 年の地図」から来たスタンドだけ、座標を同じ空港の「2025 年の地図」の別のスタンドの座標と
  入れ替える（固定の乱数）。`own_ok` は fill12 と同じで、位置だけが壊れる。

appear の列の作り方（`R_IN`・`V_TAXI` など）は変えない。

## 2. CV（`docs/appear_tier_2026-10-05/cv_standmap12.py`）

`cv_months12.py` と同じ行（2025 年 12 か月、a2）・同じ fold（月ごとに K = 5 の日の組）・同じ内側の早期打ち切りの分け方・V2 の設定。
appear の残差（A12）を 3 群で学習・予測する: fill、fill12、rand12。

## 3. 判定

「新しい行」= appear の自スタンドの列（`own_ok`・`d_dep1_own`・`d_stand_own`・`n_in_own`・`t_leave_own_lo`・`t_appear_adj`）が
fill と fill12 で違う行。次をすべて満たせば採用。
1. 新しい行で、fill12 の fill に対する RMSE の差の日単位 95 % CI が改善側でゼロを除外する。
2. 新しい行で、fill12 の rand12 に対する差の CI も改善側でゼロを除外する。
3. 全行で、fill12 が fill より悪くならない（CI が悪化側でゼロを除外しない）。

## 4. 採用なら

2026 年の appear の列を fill12（全部の月の地図）で作り直し、A12 を 12 か月・fill12 で学習し直す。差分表を
(c_A12' − c_P12)(b) − (c_A4 − c_P4)(b) で作り直す（`handoff/2026-10-06/appear12_delta.parquet` の置き換え。まだどこにも
統合されていないので 1 枚にまとめる）。b の戻し方は前回と同じ（v39 に c_P4 で）。合意した方針どおり他の施策と束ねて提出する。
