# appear を 12 か月で学習し直す — 事前登録（2026-10-06、CV の前に書く）

## 0. なぜ

v40（LB 238.77）は、v39（appear の差分は 2025 年 1・7・11・12 月の 4 か月で学習）の上に、別のセッションが「12 か月で学習した
残差」への差し替えを載せたもの。appear の差分自体は 4 か月のまま。appear の効果は学習の月を増やすほど伸びてきた
（1・7 月 −1.86 → 4 か月 −2.03 → V2 の設定 −2.24 s）ので、12 か月で学習し直せばさらに伸びる可能性がある。

## 1. データと base

- adsb.lol の 2025 年 2〜6 月・8〜10 月（242 日）を取り込み、既存の 1・7・11・12 月と合わせて 12 か月。appear の列は fill の表
  （スタンドの地図は 2026 年のものをそのまま使う）。
- base は a2（マッチ行 = `main_flseq_osm_nolirf_l2`、未マッチ行 = `main_flseq`）。OOF は 1・7 月 = jan / jul fold、11・12 月 = forward、
  8〜10 月 = aso fold（他の 9 か月で学習）、2〜6 月 = fmj fold（他の 7 か月で学習）。aso / fmj は `claude/laughing-cray-vvwh0k` の
  `docs/months_2026-10-05/local_patches/cv_aso_fmj_folds.diff` と同じ定義（設定の `folds` で名前を指定したときだけ走る）。

## 2. CV（`docs/appear_tier_2026-10-05/cv_months12.py`）

12 か月、月ごとに K = 5 の日の組、V2 の設定（v39・v40 と同じ）。各 fold で次の 5 つを、同じ検証の日について学習・予測する。
- P12 / A12 / S12: plain / appear / appear を並べ替えた対照。12 か月すべての学習の日で学習。
- P4 / A4: plain / appear。学習の日のうち 1・7・11・12 月の分だけで学習（v39 の差分の作り方）。

## 3. 判定

1. **提出に効くか（主）**: final_12 = b + c_A12 と、今の本番の作り方 final_mix = b + c_P12 + (c_A4 − c_P4) を比べ、全行（12 か月）の
   RMSE の差の日単位 95 % CI が改善側でゼロを除外すること。
2. **appear が 12 か月でも効くか（前提）**: A12 対 P12、A12 対 S12 の全行の CI がともに改善側でゼロを除外すること。

1 と 2 を両方満たせば採用。月別・空港別の差は説明用。

## 4. 採用なら

その時点の最良の提出（今は v40）を file として、file ≈ b + c_P12 + (c_A4 − c_P4) とみなし、不動点で b を戻して
new = file − (c_A4 − c_P4)(b) + (c_A12 − c_P12)(b)（= b + c_A12）とする。c_A4 / c_P4 は v39 で使ったモデル（4 か月・V2・fill）。
適用は appear の列がある行だけ。合意した方針どおり、1 秒未満の見込みなら他の小さい施策と束ねて提出する（束ねたら全部入りで
1 回 CV 確認）。
