# 12 か月 appear の残差を種（seed）3 つで平均する — 事前登録（2026-10-07、CV の前に書く）

## 0. なぜ

12 か月の appear の残差（A12、P12）は大きな木（255 葉）で、行（bagging 0.8）と列（feature_fraction 0.7）を毎回抜き取る。これまでの
CV で、列を足しただけの対照が 0.1〜0.17 s ぶれた（S12 対 P12 +0.17、fshuf 対 cur +0.13）。種を変えて学習した 3 本を平均すれば、この
ぶれの分だけ誤差が減る見込み（−0.05〜−0.2 s）。データも特徴量も変えない。

## 1. CV（`docs/appear_tier_2026-10-05/cv_bag12.py`）

`cv_lmo12.py` と同じ（1・7 月を丸ごと外す。11 か月で学習、V2、fill、同じ早期打ち切りの日）。P12 と A12 を種 s0（今の `CV.SEED`）・
s1・s2（+1、+2）で学習する（`seed` を変えると行と列の抜き取りが変わる）。`num_threads` は 4（全群同じ）。

- single = b + c_A12(s0)
- bag = b + c_P12(s0) + mean_s c_A12 − mean_s c_P12（本番の形: 本番の plain の残差の上に、平均した増分を足す）
- 参考: bagfull = b + mean_s c_A12

## 2. 判定

1・7 月をまとめた全行で、bag 対 single の RMSE の差の日単位 95 % CI が改善側でゼロを除外すれば採用。

## 3. 採用なら

最終モデルの P12・A12 を 12 か月で種 s1・s2 でも学習し（rounds は今と同じ 718 / 660）、候補 A の 12 か月の項
(c_A12 − c_P12)(b38) を種 3 本の平均に置き換えた差分を作る（A と同じく base に依らない）。
