## 探索 v2（学習月 1〜9 月だけで確認。検証月には触れていない）: 新しい情報にならない → 閉じる

仮説: 到着便はランキングでも `BLOCK_TIME` が残るので、「いま到着便で予定時刻の流用が起きているか」は予測時点で
観測できる。報告系の状態を表す新しい情報になりうる。

| 信号（LIRF マッチ出発、2025 年 1〜9 月、121,933 行、流用率 17.46 %） | AUC |
|---|---:|
| 空港全体: 離陸前 0.5 / 1 / 3 / 6 時間の到着便の流用率 | 0.505 / 0.512 / 0.527 / 0.535 |
| 同じ運航者の、その日の離陸前の到着便の流用率（因果的） | 0.602（被覆 69.3 %） |
| 運航者の長期の出発流用率（月単位の leave-one-out） | 0.724 |
| ロジスティック回帰、月の偶奇で 2 分割: 運航者の率のみ → ＋当日の到着便の流用率 | 0.6811 → **0.6848**（+0.004） |

空港全体の到着便の状態はほぼ無情報。運航者単位では相関があるが、ほとんどが運航者の固定的な癖で、その日の状態が
足す分は AUC +0.004。v1 の分類器はすでに運航者と便の識別子を入力に持つので、上積みは見込めない。**本測定に進まずに閉じる。**
