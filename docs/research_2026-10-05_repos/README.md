## 私たちの前提とずれる点・注意
- **OPDI の同一便イベント**: EDDF では 0%（merry-quicksand）。使えるのは LSZH だけで、約 5 分遅れる（smart-jigsaw）。引き継ぎの B は期待値が低い。
- **2026 年 1 月は大雪の月**（降雪 376 時間、2025 年 1 月は 84 時間）。EHAM で NM の欠測率が 1.6% から 5.0% に上がった（smart-jigsaw）。de-icing の外挿に注意。
- smart-jigsaw の不具合（Polars のカテゴリの符号が、学習とランキングで食い違った）は、私たちのコードでは起きない（`train._matrix` はソートした Enum を使う）。
- 使わないもの:
  - 2 回の LB スコアから倍率を逆算すること（smart-jigsaw §66・§71）
  - 診断用の提出（outgoing-boat v10・v14）
  - 時刻の精度・丸めの特徴（merry-mushroom）
  - ID の並び
  - EUROCONTROL の日次の出発前遅延の集計（正解の集計値）
