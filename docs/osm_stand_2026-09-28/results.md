## 3. 本番でどれだけ効くか（正直な見積もり）

- ランキングセットで 2025 年に出てこないスタンドの行は **1,589 行（0.46 %）**。そこで未知スタンド行と同じ −2.3 s
  （RMSE 約 225 の行で）が出たとしても、全体の RMSE への寄与は **約 −0.01 s**。**この仕組みだけでは LB はほぼ動かない。**
- 既知のスタンドでの効果（通常 fold でノイズ群比 K=200 −0.21、base 比 K=200 −0.34）が本物なら、全体で **0.2〜0.3 s 程度**。
- 価値があるのは、平均の改善よりも**頑健さ**: 最終評価が隠しセットで、そこに新しいスタンドが多ければ、距離の列を持つ
  モデルは未知スタンドの行で 2〜3 s 良い（LTFM・EGLL・LEMD では 5〜6 s）。2024 年・2025 年は締切前に隠しデータが追加された。

## 4. 推奨と、本番に入れる前に必要なこと

- 推奨: **採用候補**。`configs/main_gap.yaml` に `fe_osm_dist: true` を足した構成を、全 fold（jan / jul / jul_fwd / forward）で
  測ってから本番に入れる。本書の範囲では本番と提出は変えていない。
- ライセンス: OSM は ODbL。賞の条件（オープンソースライセンス）は満たすが、**帰属表示**（"© OpenStreetMap contributors, ODbL"）
  と、派生データベース（スタンド座標の表）を公開する場合の ODbL 継承が必要。`docs/README.md` の外部データの節に記載すること。
  OurAirports はパブリックドメイン。
- 取得の再現性: 6 空港は Overpass、4 空港は OSM 本体 API（`src/prc/osm.py`）。キャッシュ（`data/external/osm/`）は
  git に入らないので、再現する人は同じ関数で取り直すことになる。OSM は日々更新されるので、取得日（2026-09-28）を記録しておく。
