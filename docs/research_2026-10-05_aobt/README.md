# 予備調査: 報告オフブロック時刻（AOBT）の監査と、taxi-out 公式指標への影響（2026-10-05）

研究テーマは「欧州の空港が報告するオフブロック時刻はどこまで信頼できるか。その歪みは SES の公式指標（Additional Taxi-Out Time）に
どう効くか」。競技の順位とは独立した、航空業界向けのテーマ（JOAS 投稿を想定）である。
3 つの角度から予備調査した（`kpi/`、`clocks/`、`adsb/`）。

- データ: 競技の 2025 年データ（10 空港、出発 2,085,047 便）。公開されているのは集計値と図だけで、行単位のデータはローカルのみに置いている。
- 外部データ: PRU の公表値、adsb.lol の 4 日分（ODbL。「Contains data from adsb.lol, made available under the ODbL 1.0.」）、METAR。
- スクリプトの入出力パスはスクラッチ領域を指している。[S] は実測、[X] は推論。

## 主な発見

### F1. 公式指標をこのデータで再現できる [S]（`kpi/`）
- PRU の ATXOT の手順を実装した。参照値は (スタンド, 滑走路) ごとの P10 で、120 分を超える便と欠損を除き、de-icing は METAR から作った代理指標で除外した。
- 2025 年の 10 空港×12 か月で、公表値との相関は r = 0.993、平均絶対差は 0.10 分。年間順位は EDDF と LEMD の 6・7 位が入れ替わるだけ。
- よって、このデータの BLOCK は APDF の AOBT と実質的に同じものとみなせる [X]。

### F2. 予定時刻の書き写しが LIRF の公式値を歪めている [S]（`kpi/`）
- 書き写しと偶然の一致を分けるために、「0 分ちょうどの山が隣の幅よりどれだけ突出しているか（excess）」で推定した。
  - BLOCK = SCHED の excess は LIRF で 15.6%（どの月も 13〜18%）。LEBL は 7・8 月に 4.4〜4.6%。他の空港は 0.4% 以下。
  - BLOCK と NM AOBT_3 の一致は excess がほぼ 0 で、書き写しではない（以前の「約 21% が書き写し」という記述は誤り）。
- 予定時刻で穴埋めされた便（FILL）は LIRF で 9.4%。これらの taxi-out は平均 32.1 分で、NM の時刻で見ると 15.1 分になる。
- 公式指標への影響（年間、分/便）

  | 空港 | 補正前 | 補正後 | 差 |
  |---|---|---|---|
  | LIRF | 6.80 | 5.50 | −1.29（−19%） |
  | LEBL | — | — | −0.20（7〜9 月は −0.4〜−0.6） |
  | 他の 8 空港 | — | — | 0.1 未満 |

- **10 空港の中で年間 1 位が LIRF から EGLL に入れ替わる。** LIRF が月次 1 位だった 7 か月は、補正後 0〜2 か月になる。
- 逆に「NM と一致する記録を除外する」のは有害（+0.4〜+1.0 分）。一致している記録は、むしろ品質の良い記録だからである。

### F3. NM の AOBT_3 は多くの空港で測定値ではない [S]（`clocks/`）
- スタンド×滑走路×月の組ごとに、NM の taxi 時間が最頻の 2 分の幅に入る割合を見た。

  | 空港 | NM の集中度 | 空港 taxi の集中度 | 同じ組の中での相関（NM taxi と空港 taxi） |
  |---|---|---|---|
  | LEBL | 0.98 | 約 0.3 | −0.06 |
  | LEMD | 0.97 | 約 0.3 | −0.03 |
  | LSZH | 0.91 | 約 0.3 | 0.38 |
  | EDDM | 0.86 | 約 0.3 | −0.02 |
  | LTFM | 0.80 | 約 0.3 | 0.07 |
  | EDDF | 0.62 | 約 0.3 | 0.33 |
  | LFPG | 0.62 | 約 0.3 | 0.36 |
  | LIRF | 0.51 | 約 0.2 | 0.15 |
  | EHAM | 0.39 | 約 0.4 | 0.52 |
  | EGLL | 0.22 | 約 0.2 | 0.45 |

  空港の taxi 時間の集中度は、どの空港でも 0.2〜0.4 程度にとどまる。
- **NM の値は「離陸時刻 − 表から引いた taxi 時間」と見られる**（冬は de-icing 分が加わる形）。LTFM は北向き運用で 19〜20 分、南向き運用で 24〜25 分の 2 本の縞に約 90% が乗る。
- 着陸側の時計（MVT と ARVT_3）は、±60 秒以内に 68〜99% が入る。出発側（9〜26%）よりはるかにきれい。

### F4. 物理的な動き出しとの照合で、空港ごとの「定義の差」が見える [S]（`adsb/`）
- adsb.lol の 4 日分（2025 年 1 月・7 月）を使い、21,835 便を照合した。プッシュバックの開始を物理的な基準にした。

  | 空港 | n | 報告 AOBT − 動き出し（中央値 [IQR]） |
  |---|---|---|
  | EHAM | 911 | +15 秒 [8, 23] |
  | LSZH | 234 | −21 秒 |
  | EDDM | 641 | −30 秒（分の切り捨てで説明できる） |
  | LEBL | 381 | −22 秒 |
  | EDDF | 158 | −27 秒 |
  | LEMD | 65 | −91 秒 |
  | EGLL | 116 | −153 秒 |
  | LIRF | 40 | −105 秒 |

  日をまたいでも、1 月と 7 月でも値は安定している。報告 AOBT は、どの空港でも taxi の開始ではなくプッシュバックの開始の側を指している。
- **NM の AOBT_3 は物理的な基準と ±60 秒以内に入る行が 12〜31% しかない。** EDDM では 17% が、taxi を始めた後の時刻になっていて物理的にありえない。
- 予定時刻の穴埋めが物理的に確認できたのは LIRF と LEBL だけ。
- A-CDM-lite の「最初の信号を ready とする」代理指標は、EGLL・EDDF・LIRF では通用しない（トランスポンダが off-block から 60 秒以上後に入る行が 92〜99.7%）。

## 先行研究との差分
- APDF 仕様と PRU の指標文書は、AOBT の範囲チェックにしか触れていない。書き写しを検出する規則は無い。
- OPDI（SID 2024）の APDF との比較は件数だけで、時刻の誤差は扱っていない。
- A-CDM-lite（SID 2019）は EGKK のみで、空港の AOBT とは照合していない。
- Olive ほか（ATRDS 2025）は LSZH の taxi-out 指標で、APDF との比較は無い。
- 今回の新しい点:
  - 公式指標の再現の上で、書き写しによる歪み（順位の入れ替わり）を定量化したこと
  - NM の AOBT が表から引いた推定値であることを、空港別に定量化したこと
  - 報告 AOBT と、公開データだけで作った物理的な基準を、空港別・秒単位で比べたこと

## 弱点と次の手順
- F2 の補正は、NM の時刻を正しいとみなしている。しかし F3 で、LIRF の NM 時刻は一部が推定値と分かった。ADS-B で補正するのが望ましいが、LIRF は ADS-B の照合が 40 便しかない。
- ADS-B は 4 日分だけ。62 日分を取り込めば、EGLL・LEMD・LIRF の件数は約 15 倍になる見込み（約 166 GB、約 2.5 時間）[X]。
- de-icing の除外は METAR からの代理指標。
- 運営がデータに追加の加工（匿名化のジッタ以外）をしている可能性は否定できない。
- データの公開状況: 競技データは運営の公開を待つ必要がある。JOAS では Open data statement が必須。

## 論文の骨子案
1. Introduction: AOBT は SES の taxi-out 指標、A-CDM の評価、研究用データセットの土台であること。
2. Data: 競技データ（APDF 相当）、NM、PRU の公表値、adsb.lol。
3. 公式指標の再現（F1）。
4. 報告 AOBT の監査: 書き写しの検出（excess 推定）と、指標への影響（F2）。
5. NM の AOBT は測定値か（F3）。
6. 物理的な基準との照合と、空港ごとの定義の差（F4）。
7. 提言: APDF の品質チェックへの方向付き照合の追加、NM ベースの taxi-out の扱い、定義の統一。
8. 限界と再現性。
