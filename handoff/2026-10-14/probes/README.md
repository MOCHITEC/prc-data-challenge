## しくみ
- 1 つのセルの n 行をすべて S 秒ずらすと、旧ボードの MSE の変化は正確に (n/N)·(S² − 2·S·r̄) になる（N = 344,841、
  result.json の used_pairs と一致）。r̄ = そのセルの平均の残差（正解 − v48）。2 つの RMSE から r̄ が逆算できる。
- P1 と P3 から、LTFM の 1 月の除氷以外の行の r̄ も出る。
- 最終ファイルの同じ出発便（MVT_ID は同じ）を、r̄ − mean(最終 − v48) だけずらす。そのあと LOBT のクリップ（final の時計）と 0 の床。
- 合成した数字で往復の計算を確かめた（4 つの r̄ と、そこから出す除氷以外の r̄ を正確に復元）。
